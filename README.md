# Flip 7 
The logic for the card game flip 7

### Tests
This code base uses expect tests

> To test the code base
```bash
cargo test
```

> To update the tests in the code base
```bash
UPDATE_EXPECT=1 cargo test
```

> To run test a specific file or test
```bash
cargo test --test [filename eg.game]
cargo test [name of test function]
```
